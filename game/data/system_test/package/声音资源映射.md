# 10.14测试声音资源映射

三首配乐已按原字节收件。核心声音采用4个CC0单层测试片段，分别保留玻璃、铅笔、卡夹与短爆点的区分。它们只用于检查事件、通道、时点、暂停和停止，未做听感验收。

副2的六段演示已经有完整混音，但混音含FreeSFX素材；原制作记录规定独立音效不单独分发。本包不收这些混音WAV，不从演示MP4抽音，也不使用参考游戏原音。下列4段均取自副2已采用的CC0源音，按原有片段区间裁切并处理两端，未叠层、未重新编排。

## 二、保留现有音画时点

下面只列本轮验证用的代表触发点，不补写完整演出。相对时间从对应演出开始计算，不带演示视频的600毫秒片头。

| 动作 | 沿用的触发点 | 测试声音 |
| --- | --- | --- |
| 普通支持成立／局部成立 | 各自动作80毫秒处已有笔划时点 | 铅笔层 |
| Q02矛盾击破 | 1520毫秒主崩裂 | 玻璃层 |
| Q03灵感涌现 | 2050毫秒既有字标定点 | 卡夹层作为定点提示；不冒称原连续飞页混音 |
| 主动收下 | 收下动作开始及640毫秒卡夹落定，沿原调用 | 卡夹层 |
| 明确错误扣罚 | 120毫秒 | 短爆点层 |
| 核对失败 | 200毫秒 | 短爆点层 |
| 主动重试 | 450、520、590毫秒既有卡夹回位点 | 卡夹层 |

动作里已播放的声音不在结果节点进入时再重复播放。只替换本测试音源，演出总时长、暂停、跳过、减弱动态、成果确认和扣次规则沿现行核心与声音系统。声音事件接到程序动作后才能判定实际触发正确。
