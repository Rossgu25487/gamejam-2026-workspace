# 十一系统贯通测试用例

执行人：主程序。本文件提供测试操作与预期；游戏导入、实际操作和结果记录由主程序完成。本轮没有填写任何实测结果。

主路线为：原开头三场 → 专用文案演示 → 独立蓝盒三问 → 原结尾两场 → 固定片尾。独立蓝盒段按熟悉操作的试跑者预计5—7分钟；原五场阅读、文案演示和片尾播放另计。错误归零与重试预计增加约1分钟。以上均为估计，实际耗时由执行人记录。
