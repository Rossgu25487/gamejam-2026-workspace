# 10.14功能用例资源清单

本表对照文案以外的10册资源汇总，以及本轮T01—T28、F01—F04路线编制。按实际资源去重，同一图片在多个界面使用只计一次；正常、悬停、禁用等控件状态使用同一套组件。文案的开头三场、结尾两场人物和背景由主笔统一接收，本表只标明与其他系统的共用关系。

本包已收齐测试表使用的场景、物件、人物、表情及声音文件，已完成文件、引用与静态合成检查。尚未检查程序界面，也未进行导入或游戏运行；游戏测试由主程序执行。

| 全文与来源阅读器 | 1套 | 有图／无图、长文、准确版本、逐层来源、返回原位置 | 手册、调查检查、核心来源、目标回顾 |
| 滑杆与开关 | 各1种 | 当前值、静音、开／关、焦点、禁用 | 设置及声音相关入口 |

这些项目说明复用和制作范围。当前程序实际使用的UI文件尚未随本轮资料交来，不把“策划规格完整”写成“美术已接入”；主程序按当前实现挂接并检查上述状态。
