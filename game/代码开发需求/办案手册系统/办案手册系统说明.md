# 办案手册系统说明

配套文件：[办案手册系统策划案.docx](办案手册系统策划案.docx)、[办案手册系统配置表.xlsx](办案手册系统配置表.xlsx)。

本册仅含策划案、配置表和本说明。原型图已嵌入策划案，图源、独立图片、索引、制作脚本和音频文件均不随包提供。功能、界面与操作见策划案；本说明整合配置填写、输入输出和恢复要求。

## 1. 配置值与稳定身份

人工填写后的 Excel 是当前配置依据。表内提供手册初次页签、页签顺序和固定功能文字引用；材料、人物、版本、实际已听记录和来源由原模块及程序维护的同一内容源提供。

| 数据页／字段 | 已采用制作初值 | 填写关系 |
| --- | --- | --- |
| 手册总控 `id` | 10001 | 固定唯一一行。 |
| `defaultTabId` | 10 | 引用“页签显示”.`id`；通用入口初次打开材料页，改为20时初次打开交谈记录页。 |
| 页签显示 `id` | 10／20 | 分别为材料／交谈记录，保持稳定。 |
| `displayOrder` | 1／2 | 正整数，升序排列且不重复；可调整排布。 |
| `viewType` | 1／2 | 固定分别对应材料／交谈记录功能，顺序改变仍保留对应功能。 |
| `labelKey` | 已填对应使用键 | 标识界面位置，保留同一页签身份。 |
| `textId` | 已填对应文字键 | 引用《游戏初始化与开始系统配置表》“功能文字”.`id`。 |

当前会话已有合法页签时恢复上次页签。会面记录入口定位实际记录，调查回顾的单份阅读返回原回顾位置；这两种调用保持原入口，不改为默认页签。参数改动下次打开采用。

“文字绑定”登记关闭、筛选、来源等48处确定用途，两页签显示【材料】【交谈记录】。固定中文正文只在《游戏初始化与开始系统配置表》“功能文字”页维护；菜单、共用返回和确认复用初始化系统原键。程序可将稳定引用映射到自己维护的同一内容源。

## 2. 制作规格与表头

“##制作规格”提供可视容量、溢出和组件归属，供制作阅读，不导出为第二份参数，也不存运行状态。

| 区域 | 当前制作规格 | 显示要求 |
| --- | --- | --- |
| 材料网格 | 6列×2行 | 更多材料按原列表规则浏览。 |
| 记录列表 | 可视5段；列表538×104，三行24像素字／30行高 | 姓名12、话题／阶段18个全角字符。 |
| 原话／归纳 | 原话8行、归纳2行 | 超出独立滚动，完整内容保留。 |
| 卡名 | 24像素字，2行，每行6个全角字符 | 按共用组件提供全名阅读。 |
| 筛选按钮 | 306×48，有效宽282，选中名11个全角字符 | 下拉最多6项，每项56高，更多滚动。 |

容量只限制显示。改美术、字体或布局后，重新核对容量、换行、滚动与全文查看，恢复规则见第4节。

数据页前4行依次为 `##comment` 中文说明、`##var` 字段、`##type` 类型、`##group` 客户端分组c，第5行起为实际记录。正式行A列留空，ID唯一，必填页签引用和文字引用不可空。3张建议数据表共51条确定记录；`#备注`、以 `_` 或 `##` 开头的说明页及 `##` 注释行不导出。保留“##字段字典”核对字段含义。

“##功能示例”含 `EX_HANDBOOK_SHORT` 和 `EX_HANDBOOK_LONG`，均为示例文本XXXXXX，注明短／长内容测试用途。可单独取其文字测试显示，完整长文字保留；整张示例页及测试行不进入正式导出，不作为正式材料或会面记录。

## 3. 输入、来源与返回

| 提供方／对象 | 手册实际读取的内容 | 保持的边界 |
| --- | --- | --- |
| 核心玩法的材料集合 | 同一材料身份、实际已获版本、首次获得顺序、重点与材料版本已读 | 显示原集合，不另建收藏库存；当前待核说法不入牌库。`material_id＋content_id` 为建议引用，正式字段由程序映射。 |
| 程序维护的交谈记录 | 合法已显示原句、署名、精确说法与正文引用、已生效归纳、真实顺序及阅读进度 | `run_id／call_id`、`statement_id`、`record_content` 为建议引用。静态 `reading_rows` 与完整配置不直接作为玩家已知全文，手册不自行截取另一套可见句。 |
| 普通材料来源 | 同版各条真实取得路径 | 保留旧条目并追加另一真实路径，同一路径不重复；身份、内容版、首次顺序和正文保持。 |
| 推论及确认成果来源 | 形成时的逐层冻结快照 | 各层沿该成果的原快照展开，同内容版不切到后来扩大的普通来源集合，后来的来源不补入旧成果。 |
| 原调用页面 | 页面、问题草稿、两槽、节点、结果与目标状态，以及原入口返回引用 | 调用者维护业务状态，手册只维护临时显示和返回；不解析或执行其他系统结果。 |
| 目标导航的调查回顾 | 原回顾项、滚动、焦点、准确已获材料或合法原话、实际来源集合或成果形成时快照 | 只开共用阅读组件，关闭回原回顾；不新增目标页签，不跳默认材料页。 |

打开会面当前合法正文即记为已读，不要求滚到底或确认读完；合法新句或已生效归纳追加后恢复未读。材料版本与会面记录的已读分别维护。只读展示不提交案件进度，不改变两槽或已收状态。

完整手册检视中，I结束整个本次检视，Esc按最上层逐层返回；待收自身来源沿独立调用返回，具体输入见《办案手册系统策划案》8.1、8.3。调查回顾的显示与操作由目标导航维护，业务进展和实际依据由案件模块及程序提供；单份阅读与返回见同案8.4及《目标导航系统策划案》5.2。

来源取得和成果冻结由核心及内容提供方维护，手册只显示提供的集合。准确材料与成果记录见《核心玩法系统说明》第3节；存读范围见《存读档系统策划案》9.4“普通来源与成果冻结快照”。

## 4. 改布局后的定位与存读

显示参数按《办案手册系统策划案》第9节在下一次打开采用，本次阅读使用进入时的同一组布局。换字号、列数或可见卡数后，按原对象定位，同步翻页、键盘导航和实际点击范围。

| 恢复对象 | 定位方式 |
| --- | --- |
| 材料或会面列表 | 沿原材料、会面段或条目身份定位，再按新容量计算页码与可见位置。原锚点失效时沿该列表已有规则处理。 |
| 各正文区与来源层 | 保留同一对象、准确版本及各自正文锚点，按新字号和换行找到原文字位置；不换成最高版或另一篇正文。 |
| 来源条目列表 | 保留原来源集合与条目锚点，重新计算列表位置；正文字符位置不代替来源列表位置。 |
| 焦点 | 按原对象及控件用途恢复；对应控件已失效时采用原页面已有默认可用控件。 |

切换对象或版本仍按原规则回首行。`body_anchor` 沿《核心玩法系统说明》第3节统一接入，使用精确 `text_id` 和从0开始的 Unicode 字符位置，包含标点及换行；字段格式及实际恢复由程序落实。旧像素偏移只适用于相同布局。旧有效档缺少正文锚点时，保留原对象、准确版本和来源层级；布局已变或无法确认相同时，回该正文首行，沿当前有效控件或原页默认项恢复焦点。完整处理见《存读档系统说明》第6节。

手册、独立材料／原话／来源与调查回顾期间禁手动及普通自动新存。关闭阅读不发自动保存，返回回顾仍禁存；返回允许调查页后由原页判定。读取失败保留旧会话，成功读档结束旧调用并恢复目标档的有效记录。阅读位置恢复不提高保存资格，完整快照沿《存读档系统策划案》9.2。

## 6. 接入状态

正式剧情接入为0，未知剧情和资源保持未绑定，图中 EX 仅说明功能。程序自行确定最终内容、记录格式和字段映射，旧文案工作簿只供参考。本次已交付策划、配置与接口说明；程序尚未构建，游戏输入、内容输出、真实存读及模块联调均未执行。

## 平台与原型说明

本项目使用Windows键盘与鼠标。手册原型采用1600×900逻辑视窗，1920×1080等比输出，1280×800用于紧凑显示复核。图中示例文字只用于说明控件，容量和素材用途见画外图注。当前待核说法不加入材料集合，旧话按其实际说法版本与记录回看；材料的已读与重点标记仍由核心维护。内容格式和正式引用由程序确认，旧文案工作簿只供参考。

## 收卡演出

收卡时长由核心玩法配置维护。手册跟随演出状态，在收卡结束后解除临时检视锁，不另存一份时长。
