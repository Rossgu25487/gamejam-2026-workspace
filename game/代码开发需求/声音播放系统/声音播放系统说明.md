# 声音播放系统说明

配套文件：[声音播放系统策划案.docx](声音播放系统策划案.docx)、[声音播放系统配置表.xlsx](声音播放系统配置表.xlsx)。

本册仅含策划案、配置表和本说明。原型图已嵌入策划案，图源、独立图片、索引、制作脚本和音频文件均不随包提供。

本说明用于查字段、资源引用与声音请求的对应关系。播放条件、暂停、继续和返回的完整规则见《声音播放系统策划案》第2—6节。人工填写后的 Excel 为当前配置依据，程序可采用本表结构，或映射到自己维护的同一内容源；旧文案工作簿只供参考。

## 1. 声音总控与共用字段

“声音总控”只保留一条正式记录 `id=default`。其余数据页一行一条记录，`id` 必填且表内唯一，表示本条配置的稳定身份。

| 字段 | 制作初值／范围 | 单位与用途 |
| --- | --- | --- |
| `bgm_crossfade_ms` | 800；整数0—5000 | 毫秒，背景音乐交叉淡化时间，0表示直接切换。 |
| `ambient_fade_ms` | 300；整数0—5000 | 毫秒，环境声切换淡化时间，0表示直接切换。 |
| `menu_bgm_factor` | 0.5；0—1 | 暂停菜单BGM倍率，乘在类别增益之后，0表示菜单BGM无声。 |
| 声音事件 `event_gain` | 1；0—1 | 事件增益倍率，与总音量和所属类别增益相乘。 |
| 声音事件 `loop` | TRUE／FALSE | 布尔值；BGM、环境循环TRUE，一次性效果与配音FALSE。 |

`bus` 使用 bgm背景音乐、ambient环境、ui界面、result结果、voice配音。保留每条事件已有类别，正式资源的类别须与引用它的用途一致。音量百分比在游戏设置表维护，这里填写倍率，不填写“50%”。

## 2. 声音事件：每条请求从哪里取资源

“声音事件”页的字段如下。来源方式和实际资源分开填写，动态来源不在本行固定曲目。

| 字段 | 填写说明 |
| --- | --- |
| `id` | 事件配置键，沿下表八条已定记录；不能代替一次实际播放的身份。 |
| `bus` | 使用前述五种类别中的对应值。 |
| `source_kind` | fixed固定资源；scene_bgm当前音景BGM；scene_ambient当前音景环境声；node_sound当前合法节点／结果组的声音；node_voice当前合法节点／片段配音。 |
| `resource_key` | fixed时必填，引用本表“声音资源”.`id`；动态来源时留空，由当前合法上下文提供。 |
| `loop` | 按对应声音的循环或一次性用途填写实际布尔值。 |
| `event_gain` | 0—1的倍率，八条正式事件当前均为1。 |
| `#来源说明` | 说明当前来源和合法空值，只供制作，不导出。 |

| 已定事件键 | 类别／来源方式 | 实际资源来源 | 循环 |
| --- | --- | --- | --- |
| `SND_SCENE_BGM` | bgm／scene_bgm | 当前选中音景的 `bgm_key`，事件行 `resource_key` 留空。 | TRUE |
| `SND_SCENE_AMBIENT` | ambient／scene_ambient | 当前选中音景的 `ambient_key`，事件行 `resource_key` 留空。 | TRUE |
| `SND_UI_CLICK` | ui／fixed | 固定 `SFX_UI_CLICK`，普通按钮操作效果。 | FALSE |
| `SND_UI_CONFIRM` | ui／fixed | 固定 `SFX_UI_CONFIRM`，确认操作效果。 | FALSE |
| `SND_UI_FEEDBACK` | ui／fixed | 固定 `SFX_UI_FEEDBACK`，操作反馈／设置试听效果。 | FALSE |
| `SND_RESULT` | result／node_sound | 当前实际结果组节点的 `sound`，事件行 `resource_key` 留空。 | FALSE |
| `SND_NODE_SOUND` | result／node_sound | 当前合法文案节点的 `sound`，事件行 `resource_key` 留空。 | FALSE |
| `SND_NODE_VOICE` | voice／node_voice | 当前合法节点或结局片段的 `voice`，事件行 `resource_key` 留空。 | FALSE |

`sound`、`voice` 是当前业务提供的资源引用，不新增为这张事件表的固定素材列。可选 `voice` 为空时无配音，正文和字幕仍显示。UI、结果和配音使用效果音音量及总音量，不新增音量项。

## 3. 建议接口与配置对应

下列名称沿现有案子的接入建议，程序可按自己的内容与声音接口方案映射。每次实际播放请求使用运行中的 `event_id` 标识，同一实例重复派发沿用原ID；表内事件键、资源键及可调时间间隔均不能替代这项身份。

| 建议接口 | 使用的现有请求 | 配置对应 |
| --- | --- | --- |
| `LOAD_AUDIO` | 当前标题、场景或结局音景的加载与恢复请求。 | 读取当前选中音景，分别对应 `SND_SCENE_BGM` 与 `SND_SCENE_AMBIENT`；接受条件沿正文。 |
| `RESULT_SOUND_EVENT` | 当前合法核心表现／结果的声音请求。 | 对应 `SND_RESULT`，使用本次业务提供的实际声音资源。 |
| `APP_FOCUS_LOST` | 窗口失焦通知，按正文保留当前播放状态。 | 不另配一条音效记录；冻结与恢复处理见策划案。 |
| `NODE_SOUND_VOICE` | 当前合法节点或结局片段的音效、可选配音请求。 | `sound` 对应 `SND_NODE_SOUND`，`voice` 对应 `SND_NODE_VOICE`。 |

同一次 `sound` 播放由实际业务提供方选择 `SND_RESULT` 或 `SND_NODE_SOUND` 中的一个入口，使用同一 `event_id`，另一入口不再另发实例。声音资源的编号、类别和实际文件由程序维护的同一来源核对，本表不复制节点正文、结果或配音记录。

## 4. 声音资源与场景音景

“声音资源”一行对应一份要使用的声音，填写逻辑键、类别与采用后的资源来源。

| 字段 | 填写说明 |
| --- | --- |
| `id` | 本册资源逻辑键；声音事件的固定资源键及音景轨道键引用此列。 |
| `bus` | bgm、ambient、ui、result、voice，须与实际资源用途一致。 |
| `resource_path` | bgm／ambient填写采用素材的项目内相对路径，不填本机绝对路径；实际音频后续按采用结果交接，本次包不含音频。 |
| `resource_ref` | ui／result／voice填写程序同一声音来源的采用资源编号，实际文件由该来源维护。 |
| `#用途` | 记录已定用途、素材缺项和采用情况，不导出。 |

实际采用时，`resource_ref` 与 `resource_path` 按类别只填一项，另一项留空。当前三个UI音效的用途已定，**实际素材和资源编号仍待采用／制作，保持未绑定，当前不发声。** 已就绪资源、非空引用缺失及可选无声的处理沿声音策划案，不通过临时随机曲目替代。

“场景音景”每行对应一个标题、场景或结局上下文，以及可选的准确阶段。

| 字段 | 填写说明 |
| --- | --- |
| `id` | 音景配置的唯一身份。 |
| `context_kind` | title标题、scene场景、ending结局。 |
| `target_ref` | title时可空；scene／ending填写对应实际场景或结局ID。 |
| `phase_ref` | 填准确阶段ID；空表示同一场景通用。 |
| `bgm_key` | 引用“声音资源”中已采用的bgm记录；空表示停止BGM轨。 |
| `ambient_key` | 引用已采用的ambient记录；空表示停止环境轨。 |
| `#备注` | 注明正式采用、测试用途或待补项，不导出。 |

匹配时，准确阶段行优先于同一场景的通用行。同一 `context_kind＋target_ref＋phase_ref` 组合不可重复。空轨道键表示停止对应声音，与固定音效尚未采用的缺项分开填写。**正式场景、结局与配乐对应关系仍待采用，当前正式音景0行。**

## 5. 技术测试要联合读取

当前“声音资源”页提供 `EX_AUDIO_BGM_PULSE`：类别bgm，`resource_ref` 空，`resource_path` 为 `design/basic/test_assets/audio/ex_bgm_pulse.wav`。该引用原对应自制低音量220Hz脉冲PCM WAV，单声道、48000Hz、16bit、2秒，仅用于加载与循环测试。本次保留 Excel 中的原引用，WAV 与原来源说明均不随包提供；取得并核对对应测试音频后才能执行播放测试。

| “场景音景”测试行 | 上下文／目标 | BGM键／环境键 |
| --- | --- | --- |
| `EX_SOUNDSCAPE_TITLE` | title，`target_ref` 和 `phase_ref` 空 | `EX_AUDIO_BGM_PULSE`／空 |
| `EX_SOUNDSCAPE_HALL` | scene，`target_ref=EX_SC_HALL`，`phase_ref` 空 | `EX_AUDIO_BGM_PULSE`／空 |

技术测试读取时，**同时选用声音资源页的该EX行和场景音景页的两条EX行**，取得对应测试音频后按该项目内相对路径接入。仅读取音景并排除对应资源EX，会缺少所引用的资源。两条音景引用同一测试音频，用于标题／场景匹配、同资源保持播放位置和空环境轨的读取，不带入正式场景或配乐安排。

三条记录的A列均为 `##` 注释行，EX编号与备注说明测试用途。测试读取同时选择这些记录并提供对应音频；正式导出排除它们，正式参数保持。

## 6. 候选、文字与填写标记

“_候选样例”保留八首BGM的辨识名称、来源和未采用状态，也有候选键的旧填写示例。**数据页中的EX脉冲轨仅保留测试引用，本次未附音频。** 候选页里同名音景的BGM_CAND_01填法仅供辨识，不与当前测试数据混读；`EX_SND_UI_BACK` 也只在该非导出页示意，没有新增正式返回事件。

选择正式素材时，先核对候选的来源、授权与实际用途，采用后在“声音资源”登记对应逻辑键、类别和路径，再为实际场景／阶段／结局填写音景。候选名称不自动成为正式引用，旧demo的场景使用安排不带入当前案件。本次包不包含候选原曲或FreeSFX原音效库；后续采用资源按授权交付实际文件及来源说明。

固定功能文字唯一在《游戏初始化与开始系统配置表》“功能文字”页修改。普通提示时长 `ui_feedback_ms=2000` 毫秒同样由初始化表维护，声音表不另存一份；它只说明可见提示时长，不决定音频长度。

数据页前4行保持 `##comment` 中文说明、`##var` 字段、`##type` 类型、`##group` 分组c；第5行起一行一记录，正式行A列留空。必填数字、布尔和引用不可空，数字保留实际数值类型。`#用途`、`#来源说明`、`#备注` 不导出。以下划线开头的候选／说明页及A列 `##` 注释行不进入正式导出。采用人工填写后的实际 Excel。
