# 目标导航系统说明

配套文件：[目标导航系统策划案.docx](目标导航系统策划案.docx)、[目标导航系统配置表.xlsx](目标导航系统配置表.xlsx)。

本册仅含策划案、配置表和本说明。原型图已嵌入策划案，图源、独立图片、索引、制作脚本和音频文件均不随包提供。

本表提供目标HUD、调查回顾的实际显示初值、统一功能文字引用和独立测试数据。正式剧情为0条接入。程序维护同一内容源，正式字段和编号由程序确定；旧文案案与旧表结构只作参考。

## 1. 工作簿读取

《目标导航系统配置表.xlsx》各页第4行为表头，第5行起为原生可编辑数据。没有锁定单元格、宏或内嵌截图。数值与布尔值按原类型保存；坐标数组以`[左,顶,宽,高]`等文字形式保存，含义见中文说明。修改配置时保留对应单位，HUD基准坐标和回顾1600×900逻辑坐标分别使用。

| 页签 | 用途 |
| --- | --- |
| 组件参数 | 25项已确认HUD参数与14项回顾显示参数；这些是实际制作初值 |
| 功能文字引用 | 按稳定文字键读取《游戏初始化与开始系统配置表》“功能文字”；这里不重复定义文字值 |
| 显示引用 | 目标、文字和依据的唯一来源；正式绑定空白表示尚未接入正式剧情 |
| 资源需求 | 本模块所需组件、状态及对应图号 |
| 测试目标 | 独立显示快照；测试组ID连接测试事项，目标ID稳定标识同一主目标 |
| 测试事项 | 同一测试组内按显示顺序排列；pending为待核，checked为已核查；准确依据ID按英文逗号分隔 |
| 测试依据 | 准确对象、版本、版本显示文字、实际会话、测试正文与来源关系 |
| 测试操作 | 提供输入的顺序、玩家操作及应看到的结果，全部标为测试配置 |

## 2. 测试与正式内容

所有测试行都备注“测试配置”。TEST00的目标ID为空，表示正常的无目标输入；TEST09保留目标ID但故意缺标题，专门检查无效输入反馈。其余测试组均有可读文字与可解析的事项、依据引用。测试入口ID用于独立成功／失败回调，不对应正式地点，不构成统一关卡或剧情流程。

测试目标中的显示许可、减弱动态和暂停是原系统输入。测试操作明确要求改变这些值时，用对应真／假值提供；首次建立用initial，结果生效用result，读档成功用restore。HUD筛选公开待核事项；回顾保留同一集合中的已核查项。完成条件由案件模块计算，本表不保存第二份条件或案件进度。

同一依据的准确版本和来源在阅读期间保持。多层来源依次沿表中来源依据ID读取，返回关系按《办案手册系统策划案》8.4。阅读成功可沿原模块更新已读，准备失败不写已读；错误原因持续显示，重试开始或离开原页清除，不设自动消失时长。更新提示仍按2000毫秒执行。阅读不发完成、收下、出示或保存请求。

## 3. 模块文件与依赖

回顾显示、输入、操作和返回见《目标导航系统策划案》第5、8节。目标和事项的真实进展由案件模块提供，导航读取已生效内容；本次不另附文件清单、图源或场景参考素材。

共用层级和输入引用《游戏初始化与开始系统策划案》7.2，保存引用《存读档系统策划案》2.1、9.2，偏好引用《游戏设置系统策划案》第3—5节，声音引用《声音播放系统策划案》第3—6节，猫互动的暂停与调查返回引用《撸猫系统策划案》4.1、4.2，单份阅读引用《办案手册系统策划案》8.4。固定功能文字实际值只在初始化与开始配置表维护。

正式目标、事项、依据和资源仍待绑定。程序尚未构建，本次未执行游戏输入、跨系统往返和存读联调。
