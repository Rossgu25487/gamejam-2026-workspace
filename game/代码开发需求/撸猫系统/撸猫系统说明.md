# 撸猫系统说明

配套文件：[撸猫系统策划案.docx](撸猫系统策划案.docx)、[撸猫系统配置表.xlsx](撸猫系统配置表.xlsx)。

本册仅含策划案、配置表和本说明。原型图已嵌入策划案，图源、独立图片、索引、制作脚本和音频文件均不随包提供。

采用人工填写后的 Excel；“猫互动”“猫展示”“动作绑定”维护可调值与素材引用，“文字绑定”使用初始化系统的共用功能文字。

## 1. 已定参数与正式缺项

`cat_stove_head` 是当前互动记录，`view_profile_ref` 引用“猫展示”的 `cat_view_default`。抚摸时长 `pet_ms` 为600毫秒，回应时长 `response_ms` 为1200毫秒，均为正整数；呼噜倍率 `purr_gain` 为0.35，可填0—1。素材与时长变更同批次在下次进入时生效，当前互动使用进入时的同一组值。

正式 `scene_ref`、`cat_object_ref`、素材载体、显示几何和动作资源仍待采用／制作。空值表示具体缺项，不能据此播放占位并记为正式首见。必需素材未就绪时入口禁用，原因使用已定功能文字。

`sound_ref` 引用程序同一内容源的已采用音效，空值合法无声；首次／再次字幕引用为空时无字幕，后续由程序同一内容源登记。当前不补造正式场景、对象或剧情文字编号。

## 2. 展示比例、动作和引用

| 字段组 | 单位与范围 | 填写关系 |
| --- | --- | --- |
| `screen_x/y/w/h` | 屏幕比例0—1 | 猫素材显示槽的左、上、宽、高；宽高采用正值，范围内完整显示。 |
| `head_x/y/w/h` | 最终猫内容矩形内比例0—1 | 头部触区相对最终content_rect换算，宽高采用正值。 |
| `anchor_x/y` | 比例0—1 | 素材锚点，测试示例为底部居中0.5／1。 |
| `flip_horizontal` | TRUE／FALSE | 水平镜像，猫与头部触区同次镜像。 |
| `display_scale` | 展示倍率 | 采用正值，测试初值1；不填百分比文字。 |
| `visual_host_ref`／`camera_ref` | 实际资源引用 | 素材载体按采用资源登记；镜头只在载体确需局部镜头时填写。 |

素材按contain等比完整显示，头区跟随实际内容矩形，不能按含留白的屏幕槽直接换算。正式几何目前为空，待实际采用素材后登记。

“动作绑定”的 `interaction_ref` 引用互动记录。动作用途为 waiting等待、gesture抚摸手势、response_first首次回应、response_repeat再次回应、stable_first首次稳定姿态、stable_repeat再次稳定姿态、finish结束归位，可共用素材。播放方式 `play_mode` 为loop循环、once一次、pose姿态。首次和再次普通回应的 `stable_point` 为0—1的资源位置，当前初值0，采用后按实际动作校准；其他动作留空。减弱动态直接使用对应稳定姿态，保留原两段逻辑时钟。finish资源为空时复用idle常态归位，不新增归位时长。

## 3. 文字、测试与备注

“文字绑定”的 `text_id` 引用《游戏初始化与开始系统配置表》“功能文字”.`id`。**摸摸猫、摸摸头、返回调查等固定中文只在初始化表修改。** 可选字幕属于程序内容引用，当前未绑定。

数据页前4行保持中文说明、字段、类型和分组c，第5行起为记录。正式行A列留空，必填数字／布尔保留实际类型，ID唯一；#备注与#使用位置不导出。

猫展示中的 EX_CAT_VIEW_A／B 使用同一套比例，B仅将水平镜像改为TRUE。两行A列均为 `##`，备注说明占位与联调用途。可在测试配置中选择其中一行并使用明确测试素材；正式互动仍引用cat_view_default，正式导出排除EX行。正式资源尚未采用，本包不提供FreeSFX原音效库。人工填写后的实际 Excel 是当前配置依据。

## 接入状态

配置中的 EX 行只供独立测试，正式剧情与资源按各字段的实际绑定状态接入。程序尚未构建，本次未执行游戏测试。

## 互动范围与退出

互动不推进案件时间，不改变材料、选材草稿或人物判断。首次与再次只提供不同的日常回应，不累计亲密度，也不设次数奖励、累计成绩或冷却。退出后恢复原调查场景、镜头、热点与焦点，保留进入前的问题草稿和材料视图状态。
