# 游戏设置系统说明

配套文件：[游戏设置系统策划案.docx](游戏设置系统策划案.docx)、[游戏设置系统配置表.xlsx](游戏设置系统配置表.xlsx)。

本册仅含策划案、配置表和本说明。原型图已嵌入策划案，图源、独立图片、索引、制作脚本和音频文件均不随包提供。

“设置初值”只维护首次建立设置与恢复默认所用的值，玩家当前偏好另存独立设置文件。读取调查存档保留当前偏好。

## 1. 制作初值与单位

| 字段 | 已采用制作初值 | 填写与修改范围 |
| --- | --- | --- |
| `id` | default | 正式总控唯一一行。 |
| `master_volume` | 100 | 总音量，整数0—100，单位%。 |
| `bgm_volume` | 70 | 背景音乐，整数0—100，单位%。 |
| `ambient_volume` | 60 | 环境声音，整数0—100，单位%。 |
| `effect_volume` | 80 | 效果音，整数0—100，单位%。 |
| `mute` | FALSE | 静音初值，Excel布尔值TRUE／FALSE。 |
| `reduce_motion` | FALSE | 减弱动态初值，Excel布尔值TRUE／FALSE。 |
| `volume_step` | 5 | 一次键盘／步进操作改变5个百分点，可填整数1—100。 |

音量填70表示70%，不填文字“70%”或小数0.7。布尔值不能留空后当作FALSE。修改初值影响下次建立或恢复默认；运行中的即时生效、提交和写入失败处理沿《游戏设置系统策划案》。减弱动态只改变表现，保留原逻辑时钟和操作。

## 2. 功能文字与试听

“界面文本绑定”的 `id` 标识使用位置，`text_id` 引用《游戏初始化与开始系统配置表》“功能文字”.`id`。**本册只维护引用，固定中文文字在初始化表修改。**

试听所需的实际声音资源由声音播放系统维护，目前未采用素材的部分保持缺项说明。本表不另配第二个试听资源或声音路径；完整试听条件、原因显示顺序与恢复操作，统一见《游戏设置系统策划案》4.2“试听与零音量”。

## 3. 独立设置文件保存范围

独立设置文件由程序维护，首版格式版本为1，记录以下当前偏好。格式版本属于文件，不新增为“设置初值”页的可调参数。

| 文件内容 | 保存范围 |
| --- | --- |
| 格式版本 | 首版1，用于识别设置文件格式。 |
| 四项音量 | 当前总音量、背景音乐、环境声音和效果音，均为0—100的整数百分比。 |
| 两个开关 | 当前静音、减弱动态，保持布尔值TRUE／FALSE。 |

`volume_step` 为配置中的键盘步长，恢复默认不改变它。偏好文件不随调查存档覆盖；当前值、未保存和失败提示的同次重入、重新启动区别，见策划案7.2“设置文件读取失败”。文件读取、写入与处理状态见正文，推荐配置不另存运行中的处理字段。

## 4. 表头与测试

数据页前4行为 `##comment`、`##var`、`##type`、`##group` c，第5行起一行一记录。正式行A列留空，ID唯一，必填数值、布尔与文字引用不可空。`#备注`、`#使用位置` 只供制作，不导出。

`EX_SETTINGS_MUTED` 的四项音量仍为100／70／60／80，静音TRUE、减弱动态FALSE、步进5。它与正式行使用相同字段，A列 `##` 及备注已说明测试用途，可单独用于测试配置；正式导出排除该行。以下划线开头的说明／候选页不导出。以人工填写后的实际 Excel 为准。

## 接入状态

配置中的 EX 行只供独立测试，正式剧情与资源按各字段的实际绑定状态接入。程序尚未构建，本次未执行游戏测试。

## 平台与原型说明

首发平台为Windows电脑，使用键盘和鼠标。原型按1920×1080制作，1280×800用于紧凑窗口复核；最低支持窗口由主程序结合实现核定。固定功能文字在初始化配置表的“功能文字”页维护，本表按文字键引用。素材替换和布局重排后核对实际点击范围、焦点及容量，功能与设置记录保持。
