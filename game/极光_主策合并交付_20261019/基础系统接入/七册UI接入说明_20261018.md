# 七册UI与显示接入说明

本轮实际设置字段已写入《游戏设置系统配置表.xlsx》和config_model.json的A2表，默认显示为窗口1600×900，aspect_ratio=0自动。1600×900仅默认参考，不作为运行固定画布。

## 显示字段与唯一来源

| 字段 | 类型与值 | 应用与保存 |
| --- | --- | --- |
| display_mode | int，1窗口/2全屏，默认1 | 全屏按桌面客户区，窗口用下面宽高 |
| window_width/window_height | int，默认1600/900 | 尺寸提供16:9/16:10/4:3/21:9预设，按工作区过滤；不含标题栏 |
| aspect_ratio | int，0自动、1为16:9、2为16:10、3为4:3、4为21:9，默认0 | 自动随客户区；指定比例在客户区内生成对应有效区 |
| brightness | int，50—150百分比，默认100 | 仅场景/人物/物件受影响，UI与正文不变，结束调整保存 |

客户区W×H，指定r时有效宽=min(W,H×r)，有效高=宽/r，居中留边；自动时取整个客户区。UI按有效区中心/边缘及可用宽重排。固定镜头等比纳入完整构图；连续宽景按调查案视窗和平移范围显示，独立物件、遮挡、热区共用一次缩放及当前视角偏移。修改设置后由调查保持焦点对应位置并限定合法偏移，UI不跟场景平移。A组件5/6仅默认参考换算，禁止运行时叠乘。

模式、尺寸和比例先形成候选，点击应用后预览15秒；保留才保存。恢复/Esc/失焦/超时回到变更前全部显示值。亮度/声音等安全偏好已生效值保持。恢复全部默认若触发显示预览，取消则撤销整次默认恢复。倒计时不受剧情暂停冻结；重复确认只处理一次。

偏好格式2新增可选aspect_ratio、text_speed字段，旧格式2缺失时分别补0自动、2标准，保留原值；格式1保留原六值再补新偏好默认。当前保存四音量、静音、减弱动态、文字速度及五个显示值，共12个，不按键数识别格式。volume_step仍仅是配置步长。text_speed为1慢速、2标准、3快速，按文案唯一标准速率的0.5、1、1.5倍运行；标点停顿、单字淡入与字体色仍由文案公参唯一维护。

**程序待接：**五个显示键及text_speed需正式接入校验、偏好读写；显示另需预览/应用/回退和有效区广播，文字速度由文案消费。原型/表格完成不能代表实机已支持。实际尺寸预设见设置正文3.1。

## 共用输入与模态

共用绑定唯一源为初始化Excel的“输入绑定”，导出design/basic/input_bindings.json；设置【操作】页直接读取九组帮助。M地图、I手册、L独立对白记录、J目标回顾；Tab/Shift+Tab只移焦点，Enter/Space按当前控件推进或确认，H隐藏/恢复，Ctrl按住已看加速。撤销普通阅读Tab跳过绑定，保留点击【跳过】，不新增快存键。按钮按键提示从同一绑定读取。

Esc先退出当前详情/局部/确认/工具。隐藏正文先恢复、快读先停止，单次只做一步；没有待关闭覆盖层的普通对白或调查可Esc暂停。核心主屏自身返回按核心案，暂停的可见入口保持。设置内Esc先取消下拉、显示确认或结束拖动，之后才返回。最上层独占输入，不穿透到场景；文本输入焦点不触发字母快捷键，按住工具键不反复开关。

可操作调查主视图允许M/I/L/J；稳定问题列表、选材、普通对白/回应/选项、来源/详情/局部及结果稳态只允许I/L/J，M禁用，J的前往不能绕过原父状态移动资格。猫局部、结局保持自身返回和暂停。标题、暂停、设置、存读页、确认、显示预览、关键连续演出及提交/文件锁只接当前层输入，不缓存工具请求。同一允许父状态内切换时替换当前工具层，保留各工具浏览子层、页签、选中、滚动和焦点；退出回同一父状态，不叠开窗口。

全局手册/对白记录为右下两个170×48小入口，间隔12，距有效区右/下32；唯一几何和两个入口文字由初始化/HUD配置维护，其他系统引用。左上只场景信息，不把四项功能汇总栏搬家；物件点查、人物交谈，推理跟随当前证词。调查世界门/出口点击只给观察反馈，不直接跨地点或自动开地图；需要跨地点时可打开地图选点后点击【前往】。目标回顾等已有明确导航按钮继续按所属案及父状态资格执行。同地点的局部查看、显式视角切换及固定剧情转场沿原流程。对白播放辅助控制与两个入口分开。打开阅读/交谈/手册/地图/设置/回顾时收起目标浮窗，关闭恢复进入前展开状态及当前页。下层热区、滚轮和快捷键停用，纸纹等装饰不接鼠标。同音乐状态保持原实例和进度，UI打开/关闭和设置试听不重新起播。
