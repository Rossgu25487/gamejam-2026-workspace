# 系统交叉职责与接口

2026年10月18日。适用于当前十一系统UI、交互与完整资源交付，替换本文件中的旧制作快照与已撤销调用。共同显示要求见[界面与交互统一要求](ui_20261018/界面与交互统一要求.md)，完整功能规则归所属系统策划案；游戏程序接入尚未完成。

## 1. 唯一归属

| 对象或功能 | 维护处 | 其他系统如何使用 |
|---|---|---|
| 材料身份、已取得准确版本、取得顺序与来源 | 核心玩法及同一内容数据源 | 手册、卡牌与回顾显示同一集合，不建立第二份库存 |
| 核对目标、浅扇形手牌、双槽草稿、判定、容错、待收与收下、证明快照 | 副策划2核心玩法 | 文案按既定结果时点接续；界面查阅、悬停和返回不代替出示或收下 |
| 正文、说法原句、分支、结果内容、人物演出、实际已播放对白记录 | 副策划3文案系统 | 调查提供入口，核心提供结果，导航提供准确阅读引用；文案只记录合法呈现的内容 |
| 证物/人物浏览与详察 | 副策划4办案手册 | 读取已有材料和已公开人物；核心右下调用为只读，关闭回原草稿 |
| 共用输入、菜单与最上层分派 | 副策划4初始化与开始 | 各页面定义自身返回，关闭输入不能穿透到场景；详情与工具层优先退出，无待关闭覆盖层时Esc暂停，普通对白暂停保持可达 |
| 保存资格、读取恢复、保护节点和失败恢复 | 副策划4存读档 | 页面只提供实际上下文；临时检视不改变原保存资格，不能用旧快照冒充当前状态 |
| 当前场景、物件与人物热点、局部视图和对象层 | 副策划5调查与场景交互 | 点击精确入口，按真实结果显示已查/可补查；绘制与热区共用场景变换 |
| 地点目录、楼层、目的地预览与准备 | 副策划4地图切换 | 场景准备成功后采用同一current_scene_id；选择、预览、取消不改变地点 |
| 目标显示、折叠和调查回顾 | 根工作稿目标导航 | 读取实际开放和完成状态；指向真实可进入的调查/话题，回顾不自行推定目标完成 |
| 画面设置、有效显示区域与偏好保存 | 副策划4游戏设置 | 默认1600×900，所有页面消费同一有效区域；不另存固定比例或重复5/6缩放 |
| 音乐、音效资源与播放实例 | 副策划4声音播放，编曲师提供实际文件 | 文案/核心等请求实际事件与资源ID，同曲续播；文件路径和登记ID分开 |
| 猫的专属互动和动作同步 | 副策划4撸猫 | 由场景猫热区进入，实际动作/图层随包，不增加全场景常驻摸猫按钮 |
| 章节、世界条件、人物剧情地点、开放状态与合法结果执行 | 同一内容/流程状态，策划提供实际节点和条件 | 所有系统消费同一状态；查看、点击或重建UI本身不完成剧情 |

十一册由原负责人维护同源正文、Word、配置及原型。根统一共同依据、接入说明和正式包，不从其他目录的同名旧表猜当前版本。

## 2. 核心卡牌与手册

说法核对使用已听过的准确statement版本，自主推理使用已开放的reasoning问题；目标不进入玩家材料集合。两个出示槽最多容纳两份不同身份材料，左右槽不改变关系匹配，单份充分时可以直接出示。精确版本、充分关系、容错和推论生效时点沿核心案。

核查页直接显示浅扇形手牌。点击空槽仅确定放牌位置，卡带点击选入，玩家主动出示才判定。核心空槽唤起手册选材的旧路径停用。卡片详情和准确旧版回查就地展开，关闭回同一目标、草稿和浏览位置；手册右下入口提供完整只读查阅。其他系统真实需要的情境出示按所属案维护，不重新连接核心的旧选牌流程。

手册保持证物/人物两个页签；对白记录是独立阅读入口，由文案提供实际已播放内容。两入口固定有效显示区域右下，打开后由当前页面独占输入，关闭恢复原调用处。

手牌排布改变时重新计算显示张数、分页和焦点，完整已获集合保持。悬停不选牌，翻页不提交，视图缩放不改变版本、问题状态或容错。卡片的图片和证明内容改变时，仍按材料版本规则处理。

## 3. 取得、观察与世界对象

取得材料记录只更新知识集合和准确内容版，实际移走物件由明确剧情行为触发。尸体、窗户、饭具等观察记录可取得后保留现场实体。收入物证袋的对象使用明确完成事件；仅查看、掀起或读卡不自动隐藏实物。

普通材料同版的真实新取得路径可追加来源，重复路径不重复追加。已确认成果和推论的实际依据在形成时固定，后来的资料或新版本不回填旧证明。待收推论由玩家主动收下才进入可选集合，完整演出或跳过不代替收下。

案后背景持续状态读取实际场景/章节/事件，不依赖某一段对白是否仍打开。表内scene_background、fixed_view及对象图片各按其用途读取，避免正文结束回到案前底图。

## 4. 直接调查、人物与局部视图

物件各自在画面真实位置配置热区，点击调用该热区的准确检查入口。相同实体可以有额角、腹部等多个检查区域；禁止按object_ref聚合成反馈菜单。初查、重访和阶段差分按当前条件自动选择。鼠标悬停用放大镜表示可调查状态，已查和可补查沿实际内容结果，键盘保留必要焦点；全场景与局部均撤销“物品名＋点击检查”等悬停浮签，点击后的反馈仍由文案入口提供。

场景背景、独立对象层、遮挡与热区共用原图尺寸及同一等比变换。局部图使用自己的视图身份、显示矩形和热区；进入时保存上一视图，退出恢复，返回入口与观察项数量无关。

独立交谈人物使用屏幕近景和真实人体锚点，不画成地面小人。背景内已绘入且可交谈的人物使用配对背景：原位置透明热区→去除当前对象的同机位背景及中央正面近景→结束按实际剧情恢复。尼娜需覆盖大厅主图和柜台局部；其他实际同类对象逐项绑定。无话题只反馈，场景不变。多名背景人物只去除当前进入前景者；纯剧情CG及遗体按各自用途处理。

前景立绘按实际朝向与舞台位置匹配：朝右姿态放左侧，朝左姿态放右侧，居中使用正面或近正面。文案提供准确姿态与站位绑定，美术明确实际画面朝向，各调用系统沿用同一对应关系；核心固定对手区域也须选相容姿态。同一会话换表情保持站位，不靠默认镜像改变不对称衣着、伤痕与持物。

背景临时交谈显示与人物剧情地点分别维护。暂停/手册期间保留交谈图与中央人物；剧情已经转场或人物离开时，退出按新的合法场景状态恢复，不能强行恢复旧人影。

## 5. 阅读、结果与返回

普通对白采用文案逐字和语意分页；心声、观察和时间地点按实际类型显示。全部页面播放完毕后才触发该条文案的完成结果，分页不重复提交。核心反馈、待收与失败页面沿核心的阅读和确认规则。

记录只追加已经合法显示的内容，未来分支不进入记录；打开时默认定位最新，主动回看时保留阅读位置。普通材料完整阅读记实际版本已读，预览和悬停不代替阅读，不加二次确认已读。

每次打开详情或模态保留调用页面、对象、准确引用、草稿、文本位置及焦点。Esc先退出当前详情/局部，再关闭工具层；没有待关闭覆盖层时可进入暂停，普通对白不因此失去暂停入口。隐藏和快读等页面状态依文案案先恢复，核心玩法页自身的返回与暂停沿共同输入矩阵。设置中的显示预览按设置案回退。当前层消费输入，不能同次关闭又触发下层按钮。

暂停、跳过、关闭与返回不重复结算，也不清除已经成立的事实。各稳定与过渡状态的保存资格只从存读档案读取，页面不能自行开放新保存节点。

## 6. 地图、目标与推进

地图预览不更改当前位置，正式切换准备完成后才采用同一current_scene_id。失败和取消保留原场景与上下文；跨层切换不混入另一层旧图。普通移动不自行推进故事时间或新增自动存档。

地图按实际车站结构展示两楼层与楼梯连接，采用简化轴测模型或对应离线分层图。货车有独立地点入口；站外前门/货车以及实际存在的后门按场景与视图职责建立，地点选择、场景移动和视角切换不能混用。美术提供模型/图层与原图节点，地图维护地点对应，调查维护该视图的对象和热区。

导航回顾的“前往核对”属于明确的系统操作，必须对应实际可进入的地点及入口，准备失败留在原回顾项。用户10月19日取消场景门口点击直接跨地点的入口：世界门口只保留实际观察反馈，地图继续提供自由探索的地点选择与明确前往；同地点视角/局部及剧情转场保持。读取存档使用待恢复世界准备场景，不按当前世界错误补首访、材料或自动保存。

地图中的其他人物棋子读取玩家已确认的位置事实；实际剧情世界位置继续由内容状态维护，两者不能混用。当前可见场景与明确公开事件提供确认来源，地图负责展示，存档负责同源恢复；资料头像、卡面、回忆和地图棋子的渲染不反向写入确认事实。姓名/头像沿同一人物当前已公开资料，未知位置不从后台真实位置补齐。

CH01货单路径须经E05实际阅读及后续事件完成；看过借笔或问话段不替代阅读。其余目标同样按真实结果完成。目标浮层在阅读、交谈和模态打开期间收起，关闭恢复进入前展开状态。

## 7. 显示、声音与资源交付

1600×900为初始默认，玩家可调整分辨率/比例。设置提供有效显示区；UI按锚点、可用宽度、阅读限宽和分页布局，场景与热区保持对应。A原1920制作尺寸的5/6仅默认参考换算，运行中不重复叠乘。

章节、场景和同章合法故事进度共同决定当前配乐，由文案/内容状态发出明确请求，声音系统解析实际资源并维护实例。相同地点的日常、案后调查、证词变化和揭露余波按实际段落、配器发展、过渡与留白适配，不把同一循环改名当变化。相同音乐状态继续当前位置，UI打开关闭和普通点击不重播音乐；临时演出结束回当前进度音景，避免恢复过期曲目。卡牌悬停音只在合法状态进入时短触发，不随每帧或鼠标移动连续播放。关键演出音效按实际接触/落位时点绑定。

正式包提供实际美术/声音文件及所需配置：热区、物件、UI组件、场景、立绘、头像、图标、演出的位置、锚点、层级和资源路径。真实缺项本地生成补齐，保持画风/音乐方向，来源和许可证随包。规则先写所属策划案，配置负责确定内容和资源绑定。

旧素材绑定中的EXAMINED不自动等于取走事件，旧演示工程、占位场景、测试正文和旧路由不进入当前运行配置。所有缺失引用须完成补件或纠正实际绑定，禁止静默替成其他人物或通用错误图片。

## 8. 交付与独立审查

本轮根和各负责人完成必要制作检查后，本地封包和提交，不推送远端。策划/静态原型完成与游戏已运行分别报告，程序必须接入的新增读取和状态差异见包内说明。

用户指定的“主策划”在整套成品完成后独立审核十一案、系统功能、视觉、配置与游戏整体体验，按[独立审查交接](交付说明/主策划独立审查交接_20261018.md)执行。开始审查前给出准确包路径与提交，避免对中途文件重复检查。
