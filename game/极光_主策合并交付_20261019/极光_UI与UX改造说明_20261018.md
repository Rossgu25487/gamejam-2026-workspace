# 极光｜UI与UX改造说明

2026年10月18日。配套文件为本包十一套策划案、对应配置表、实际组件与页面原型。各系统规则以所属策划案为准；本文说明共同改动及接入顺序。

## 视觉依据

采用人类美术A最新水彩纸感UI、梦源黑体与人物v3，B版补充卡框、状态和推理表现。当前冬夜场景、物证与故事身份保持各自实际来源。演示包里的白天背景、占位人物、示例地图和业务跳转退出正式接入。

阅读与信息框统一为微厚度浅羊皮纸，纸面连续整洁、纸边仅有细微自然起伏。操作按钮沿用A版水彩笔触、纸纹与暖灰米色，通过完整的微不规则轮廓、手绘描边、薄厚边和短投影呈现按键感，明确区分主次操作及悬停、按下、禁用状态；菜单和右下手册、记录入口同样采用按钮组件。碎纸片、撕裂长条及规整光滑的软件按钮皮肤均退出。普通正文深墨`#34413F`，时间地点深绿`#3F6B4C`；短标签按完整文字收紧，长文合理限宽分页，逐字开始前确定整页框体，跨系统共用材质、字号、边距和状态。

场景及局部视图的物件、可观察门口和背景人物，悬停时分别使用放大镜或交谈光标，保留必要键盘焦点；撤销名称及“交谈”“点击检查”“点击前往”等文字浮签。点击后的调查反馈、正式对白、场景标题和真实返回按钮保留。门口点击直接跨地点的旧入口已按用户10月19日纠正撤销；自由探索通过地图选择地点再点“前往”，同地点视角、局部及剧情转场沿原流程。

梦源黑体 Dream Han Sans CN W12/W16 使用SIL Open Font License 1.1，可用于商业游戏并随游戏嵌入。正式包保留字体目录中的版权、完整许可证和来源文件；字体文件不单独售卖。新增字体优先选用有明确开源商用授权的字体。[官方来源](https://github.com/Pal3love/dream-han-cjk)。

1600×900为默认值，支持设置调整分辨率与画面比例。不同宽高比下，UI按有效显示区域和锚点重排；固定镜头等比纳入，可平移宽景按视窗显示且全部调查区域可通过移动到达，物件与热区共用一次缩放及当前偏移。A的1920×1080制作尺寸仅在默认稿中换算为5/6，运行中不能再重复缩放。

## 玩家操作与显示

场景保留足够可见面积，左上横排显示地点和必要时间，撤销常驻功能汇总栏。物件直接点查、人物点击交谈，门口点查保留观察反馈。办案手册、对白记录固定在有效显示区域右下角，随比例适配边距；对白控制与它们分开，避免遮挡文字。目标采用紧凑可折叠提示，模态页面打开时收起目标并阻断后方输入。正文、手册及设置各自使用适合长时间阅读的版面，装饰贴图不拦截点击。地图的双层空间模型保留棋盘承托、格面节奏和地点标记，空间关系与移动规则保持。

常用快捷键按初始化案统一，M开关地图、I开关手册，其他键位与对应控件提示保持一致。工具切换保留原父状态和各自浏览位置，Esc优先退出详情、局部、确认和工具层，没有待关闭覆盖层时可暂停，普通对白的暂停入口保持可达；输入不能穿透到被覆盖的场景，关键演出和显示预览沿各自明确锁定与回退规则。

地图按真实车站结构尝试可分层展开的简化轴测模型，清楚显示两楼层、房间和楼梯连接，提供实际模型或离线地图图层及节点坐标。货运卡车有独立地点入口，站外区分前门与货车视角；后门以实际空间为依据。地图与对应场景、物件热区、移动及返回入口共同更新。

人物棋子的位置只读取当前存档的 `confirmed_actor_locations [{actor_id, scene_id}]`，每个人物保留一条玩家已确认位置。真实场景或公开事件确认位置时更新该人物，明确公开离开或位置失效时移除，读档原样恢复；不读取真实 `npc_scene`，不从回放、卡片阅览或地图绘制新增确认。

物件按画面位置设置独立热区。悬停到可调查位置时有明确放大镜反馈，点击直接播放当前有效观察或进入必要局部；同物件的新旧阶段自动选择，玩家不再从同义列表挑反馈。局部查看提供返回上一视图，关闭后保留原调查位置。

全部调查项都有实际可达画面中的可见目标。连续宽景可左右平移，独立镜头提供明确视角切换，详情/交谈后返回原视角与偏移；单图看不到的内容实际补视角或局部，调查汇总列表退出正式流程。

独立人物采用前景半身或膝上近景，按可见人体与切线等比定位，透明留白不计身高。调查模式收起前景人物时不改变其剧情地点；交谈恢复同一站位。大厅尼娜沿两张同机位背景处理：平时显示含尼娜背景，在图中她的位置直接点击；有对话时切无尼娜背景并显示中央交谈立绘，结束清除立绘，她仍在厨房时恢复含尼娜背景。无话题只反馈“还是别打扰她了。”，不切图、不出立绘。头像、姓名、发言者与立绘按各自用途正确绑定。

前景人物朝向画面内部：朝右的姿态放左侧，朝左的姿态放右侧；居中交谈优先使用正面或近正面。实际朝向、姿态资源与舞台位置分别绑定，同一会话换表情保持站位。缺少相容姿态时选用已有合适图或补画，不默认翻转衣着、伤痕、持物不对称的立绘。

取得材料、记录观察与移走实物分别处理。格兰特遗体的记录进入手册后，遗体仍在现场；后续查验、出示和更新版本也不移除遗体。明确收入物证袋的物件才按实际剧情事件移走。场景持续状态不由一段正文是否结束决定。

背景内人物的交谈切图覆盖所有实际同类场景，逐项交付有人图、去除当前交谈对象的同机位图、原位置热区、前景图及恢复绑定。其他背景人物保持实际在场状态；纯剧情CG与固定调查对象不自动套用此流程。

短反馈、材料阅读和会话结束后回原调用位置。普通阅读自动记录准确版本的实际已读状态；推论主动收下保留。对白记录定位最新，分页按完整语意处理，避免极短尾句孤立成屏。相同音乐请求及普通UI返回保留原播放位置。

配乐按章节、场景和实际故事进度配置合适段落。相同地点的日常、案后调查、关键证词变化及揭露余波采用实际音乐发展、配器变化或留白，重要节点提供过渡和环境声空间。演出结束接回当前场景当前进度，禁止恢复过期音乐或用未揭示信息提前暗示案情；相同音乐状态保持连续播放。

核心核查按目标/对方、中央出牌区、下方浅扇形手牌整体排布。普通选牌在当前画面内完成，点空槽只确定放牌位置，撤销空槽唤起手册的旧路径；卡片详情与旧版回查就地打开，手册保留完整只读查阅。两处共用相同材料身份和准确版本。卡面以2:3竖向硬卡轮廓、纸纤维、薄边、投影和克制金属高光体现质感，证据/证言/推论采用不同低饱和纸底色与淡底纹；悬停抬起、选中入槽、主动出示与推论收下持续呈现同一类别卡面。六稿问题、判定、容错和演出时点保持，选牌与出示继续分开。

## 废弃内容与正式范围

旧的小全身人物、泛物件选择菜单、拾卡即隐藏实体、固定16:9界面和未区分引用键/文件路径的处理，退出当前有效案文与配置。旧素材和模板不继续作为生成依据。

正式包仅收当前实际采用的资源与必需依赖。原始美术交付包、历史正式包及制作源码在各自位置保留；预览截图、示例工程、匿名测试记录和临时中间产物不进入游戏接入目录。需要程序新增或修正读取的部分见另一份接入说明。

本次为本地策划、配置和资源交接。游戏代码接入及实机验收由主程序完成，静态原型与案表不代替实际游戏输入和状态检查。
