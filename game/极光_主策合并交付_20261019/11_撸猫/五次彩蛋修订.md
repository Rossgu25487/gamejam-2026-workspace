# 极光 撸猫五次线索彩蛋

在SC02大厅累计完成五次摸头后，取得一次观察记录《水碟下的干印》。它为L15终局第三轮提供一条可选思路，原关卡依旧能够用主线材料完整通过。该记录和显露过程为本轮新增日常细节，案件经过、证人知情和必需材料保持。

本稿替换当前撸猫案中“不改变调查资料”“不设次数奖励”的对应部分。进入条件、2800毫秒同轴动作、首见、暂停、减弱动态和原场景返回继续沿当前撸猫案；下列第五次完成后的短观察替代该次立即返回。当前生产源为副策划4的design/cat/cat_plan.json及实际《撸猫系统配置表.xlsx》，本次已合入交付配置与资源，正式游戏接入仍需实机验收。

## 1 玩家会看到什么

前四次保持现有摸头回应。第五次完整回应结束后，猫仍停在原局部，接一小段水碟特写和艾琳的观察，随后普通成卡，再回原大厅。开头不显示次数、进度条或奖励预告，不增加任务导航，也不新增“领取彩蛋”按钮。

新增画面顺序：炉边原有摆放位置增加小水碟；第五次摸头结束，猫伸懒腰碰到碟沿，少量水先溅到碟子周围的木地板；艾琳抬起水碟擦拭，底下露出干燥圆印。必须先见水流过，再见水碟移开，干印才具有明确来源。该段只表现日常泼水，不借猫的行为指认任何案件人物。

每行玩家文字为一页：

| 类型 | 正文 |
| --- | --- |
| 观察 | 猫伸了个懒腰，碰得碟里的水洒了一点。 |
| 叙述 | 我抬起小水碟，底下露出一圈干印。 |
| 心声 | 水从旁边流过去时，碟子已经放在这里了。 |

整段阅读结束，取得普通观察记录并播放现有普通成卡反馈；不采用推论待收，不播放矛盾击破或灵感涌现。猫和水碟继续属于场景，收入手册的是记录。

原成功条件优先：出示集合已含满足原条件的E04时，照常成功，不能被同槽E27的辅助反馈截断。只有E27而没有满足成功条件的材料时，才走上述心声；E27与无关材料同出也不会代替E04。重复出示可重读同一短反馈，不再发奖励。

未取得E27的玩家保留原有追问、思考提示、问答选项与E04出示路径。关卡进入、证言开放、原提示触发、正确判定、章节推进及结局均不得查询E27是否持有，也不增加“先去摸猫”的导航或提示。

取得时不写药瓶、酒壶、冷汤、凶手或案件时间。L15前两轮及准备关联的材料要求保持；此条仅提供可类比的观察，不能作为任何人的作案证明。

## 3 五次怎样计数

每次实际完成既有2800毫秒摸头回应时加一，计至5即停止累加。等待页、只打开猫画面、点击空白、被禁用的连续输入、长按重复事件均不计数。触摸中提前返回不增加本次次数；暂停和失焦沿原时间轴冻结，恢复后完成仍只算一次。减弱动态仍按原2800毫秒逻辑时长完成一次。

次数按同一调查累计，允许在不同次进入大厅、不同章节间继续。前四次仍按原规则自动回调查，第五次接本稿短观察；奖励已取得后，第六次及之后恢复普通回应，不再出现干印奖励。

只新增必要的当前调查状态cat_pet_completed_count，取值0至5。首见继续使用原标记，不用“见过第24帧”代替“完整摸过一次”。新调查为0；旧档缺少该字段时从0开始，不根据首见推算已摸次数。

第五次完成即记到5。若玩家在短观察结束前返回，保留5次及尚未取得E27的事实；下次进入猫局部直接继续短观察，无须第六次摸头。奖励是否已取得读取现有材料持有记录，不另存一份重复领取标记。普通成卡的取得事件只提交一次。

次数和材料持有随既有调查快照保存；猫互动、短观察及成卡中保持原禁存规则，返回大厅不新增自动保存。读档恢复对应快照，已取得E27的档不补发，4次的档仍从4次继续，5次且未取得的档继续短观察。重新开局清零，存档回退属于该档的正常进度回退。

彩蛋继续服从猫入口的合法时点：SC02可自由操作、猫在场、当前无固定对白或关键演出。首章单线与终局连续对质不因奖励而开放额外移动。没有取得彩蛋的时间窗口，不构成主线阻塞。

上述编号为本轮新增分配，应进入各所属内容表后统一查引用。E27与相关文本只保留一份内容源；撸猫表、核心表与布局均以引用消费，不能各自复制不同正文。原E01至E26、T系列、P系列身份不重排。

当前56张猫帧、56张手帧只覆盖既有摸头动作，不能冒充水碟彩蛋演出。新增特写可用三张短切画面表达原位、泼水、抬起后的干印，配合本稿三页文字；不要求重做112张现有帧。图片按同机位同水碟同落点制作，干印位置必须对应前一画面的碟底。减弱动态沿同样三幅静态画面与文字顺序，不补播动作。

局部期间停用大厅整组热区、悬停反馈和焦点。新特写只开放阅读、返回与暂停；水碟和干印不建立额外点击热区。返回时恢复原scene、view与平移位置并重新求当前合法热区，消耗本次返回输入，防止误点到全景炉灶、猫或柜台。原猫头热区继续绑定实际完整画布和归一化头部，不能复制特写或全景的像素坐标。
