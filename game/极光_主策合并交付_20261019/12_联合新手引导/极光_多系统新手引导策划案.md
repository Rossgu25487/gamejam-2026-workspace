# 极光 多系统新手引导策划案

## 1 引导目标与展开顺序

玩家跟随艾琳进入货运站，在第一次使用新系统时完成一次必要操作，引导随即结束。调查只教第一次点击物件，地图只教第一次移动；阅读翻页、进门、后续取证与关界面沿正常流程进行。核心玩法在T00中完整体验首次成卡、一张与两张材料的用法、矛盾击破、灵感涌现和主动收下。

第一章采用用户提供的八稿核心概念中的受控路线。角色原话与证据事实沿本次收到的最终文案，路线调整涉及的段落迁移和收尾列在第9节；所有新增操作说明单独作为界面提示，角色不讲按钮和系统规则。

| 阶段 | 玩家当前目的 | 本次学会的操作 |
| --- | --- | --- |
| SC01 站外 | 确认到达正确车站 | 点中站名牌、观察正文出现即结束调查教学 |
| SC02至SC06 | 按洛恩指引上楼取暖 | 在首次地图中选SC06并移动一次 |
| SC06 休息室 | 整理受潮的移交清单 | 正常取得E01并看见成卡；不强制进入手册 |
| 首次主动打开手册 | 查阅已知材料 | 打开一条材料正文即结束，后续自行返回 |
| SC02 大厅 T00第一轮 | 核实册子的实际年度 | 一张材料充分，第二槽留空，主动出示并体验矛盾击破 |
| T00第二轮 | 将已核实册子对应到清单项目 | 两张材料共同证明，主动出示，体验灵感涌现与新卡收下 |
| 第二章首次质询 | 对已听原话继续询问 | 选择一句正确原话并追问一次；选材出示沿T00已学操作 |

后续普通调查、人物点击、材料更新、I01两卡关联及P01收下不再强制重教。目标、对白记录、设置和存读档使用原有入口与控件说明，不额外组织一串开关界面任务。撸猫、宽景平移等确有新操作时，在玩家首次实际使用处介绍一次。

首次成卡和结果演出随真实业务结果自动呈现，不各自增加一个“播放演出”按钮。只为完成当前新操作保留必要输入，演出体验不增加确认弹窗。

## 2 完整引导层与操作锁定

### 2.1 首次示范直接给出正确操作

每种关键系统第一次使用时，直接高亮正确对象、正确证言或正确材料，配合箭头、框选动效和文字，带玩家亲手完成一次。第一轮示范不要求玩家自行寻找答案。实际操作成功后撤去引导，再恢复自主调查与判断。

正确答案必须属于当前已公开、已获得且能合法使用的内容。引导按当前问题和精确材料版本定位，不提前公开后续案件结论，也不绕过调查取得条件。首次操作前缺少材料时，先接上它的合法取得流程，目标和控件就绪后再启动对应步骤。

每次只强调一个主要动作。选材阶段直接指向正确卡，出示阶段转向出示按钮；两份材料关联分两步依次指出正确材料和目标槽。其他卡片与证言仍可见，但当前步骤不可选，避免第一次使用就卡在试错中。

### 2.2 六种表现同属一个步骤

背景遮罩、局部高亮、区域锁定、箭头、框选动效和文字教程共用同一个当前步骤。它们同时指向同一目标，不能文字已经进入下一步、箭头还指着上一步。

| 表现 | 默认效果与参数 | 必须保持的关系 |
| --- | --- | --- |
| 背景虚化 | 非目标区域采用6px高斯模糊并叠加约55%深色遮罩 | 目标、教程文字和必要阅读内容保持清晰；游戏画面不切成另一场景 |
| 局部高亮 | 目标保持原色和清晰度，外扩10px留白，使用暖金描边 | 高亮依据真实控件或物件轮廓；外扩光晕不扩大真实点击范围 |
| 区域锁定 | 仅开放当前正确目标、该步必要返回与暂停入口 | 鼠标、键盘、焦点导航和快捷键使用同一放行范围 |
| 箭头指引 | 箭杆、箭头头部与线宽均缩至原示例的1/3 | 尖端固定在目标边缘内侧约2px，按0.9秒周期明暗变化 |
| 框选动效 | 约0.26秒描出边框，随后按1.2秒周期轻微呼吸 | 框住正确对象或控件；正文阅读区可另开清晰窗口 |
| 文字教程 | 浅羊皮纸、深墨正文，沿玩家当前逐字速度显示 | 与高亮和动效同时开始；播完保持等待操作，不自行跳步 |

上述像素以900高参考画面为基准，随有效显示区域等比适配。教程纸签靠近目标，避开人物脸、证言、目标本身和必要阅读内容；画面变窄时换侧或换行，不能缩成难读的小字。常用15至35个可见字符，单屏最多40字。框体按整页内容预先测量，逐字期间尺寸稳定。

高亮绑定实际卡牌节点与材料身份，点击继续沿卡牌系统原有的命中、裁切和层级规则；引导只过滤当前允许操作的对象，不用一块新矩形代替原卡的点击范围。扇形旋转、重叠、悬停抬起、分页和入槽后，重新读取当前目标的实际变换与显示范围。外扩描边只负责视觉提示，框内的空白、透明边及被其他卡遮住的部分不会因此自动变成可点击区域。

原型卡面与最终资源的比例、透明留边或组件布局不一致时，原型截图不能作为正式热区验收依据。最终接入必须在实际卡牌组件上核对上述状态；禁止复制本原型中的绝对像素坐标作为游戏点击范围。

步骤进入的第一个时刻先锁输入。遮罩和虚化约0.18秒淡入，框线、箭头和文字在同一时刻开始呈现；目标一旦可见即可操作，不强迫等文字播完。完成后约0.18秒撤去本步表现或切换目标；触发输入当次消耗，不穿透到下一步。

“减弱动态”开启时，保留静态高亮、完整箭头、文字和区域锁定，停用箭头明暗变化与框线呼吸，模糊切换采用短淡变。箭头不做位移动效，尖端保持对准目标；箭头与框线不循环播放音效，打字音只响应实际新增字符，快显、暂停恢复和重绘不补播整段声音。

### 2.3 一次新操作完成就撤层

引导中点击遮罩、错误卡片或未指定控件不执行后方业务。鼠标、键盘和快捷键共用当前放行范围，必要返回与暂停始终可用。取消只离开当前操作，回来时继续未完成的新操作，不从最早一步重新教学。

调查教学以正确点击已打开实际观察正文为完成；地图以真正到达为完成；手册以打开条目正文为完成。完成即撤去遮罩、虚化、箭头、框线和教程文字，不继续教读完、关界面或走到下一处。剧情阅读、取得事件和场景解锁各自按原规则执行，教学完成不代替剧情完成。

核心教学以两轮真实核对分别成立、演出完整呈现、结果卡主动收下为完成。它覆盖第一次完整核心操作，所需选卡与出示是同一操作链，不能省成只点一张卡，也不拆成多个重复弹窗。

点物件后仍可有正常阅读模态；关键演出和提交中仍按原业务限制输入。这些状态由游戏本身维护，不能为“保持教程锁定”额外延长。已学过的同类动作不重复出现教学，即使换了地点、对象或材料。

## 3 第一章的最短引导

### 3.1 调查只教点中一个物件

首次到达先在下方文本框显示时间与地点，左上常驻地点保留。时地页与开场心声沿普通阅读播放，结束后再高亮站名牌，箭头、框选动效、文字和背景虚化同步出现，提示：“点击画面中的站名牌。”只放行站名牌和暂停。

玩家点中站名牌，实际观察正文出现时，调查教学立即完成并撤去全部引导层。后续正文正常逐字与翻页，读完后按脚本开放大门，玩家自然点击进屋。大门、清单、人物和后续物件不再重复教点击。真实观察已查、剧情推进和材料取得仍等待各自原有完成条件。

### 3.2 地图只完成一次移动

洛恩递图并让艾琳上楼后，地图入口显示正常M键标识。首次打开仍显示当前楼层；若SC06尚不可见，先高亮二楼页签，切到二楼后再指向休息室与移动按钮。目标已经可见时不要求重复切层。用同一条“找到二楼休息室，再点击移动。”贯穿这次操作，成功到达SC06即撤层。

取消或准备失败不标记到达，再次打开继续当前地图操作。第一章各地点的可达范围服从单线路线，地图教学不额外开放房间，也不再教关闭地图或返回大厅。

### 3.3 E01首次成卡要实际看见

玩家按正常调查操作查看移交清单，完整听完原对白及洛恩回应。合法取得事件提交时，E01立即进入持有集合，随即播放现有400ms普通成卡表现：纸纤维汇拢显卡、卡片沿弧线飞向手册入口、落点描边。

取得后沿现有反馈停留约2000ms，清楚显示名称与卡面，并用一句“调查所得会记成卡牌，可用于之后的核对。”说明用途。此处不另开教学弹窗、不要求点击“收下”，也不强行打开手册。第一次观看时保证镜头和下一段剧情不会瞬间盖住整段成卡；停留结束自然继续，不增加确认操作。

E01只展示当时已知的移交要求，不提前显示E23健康复查表。取得记录不移走画面中的原物件。玩家首次主动打开手册时，只引导打开E01或当前有效条目的正文：已有选中条目则直接指向【详察】，尚未选中时先点条目再转向【详察】。正文打开即撤层，返回沿正常控件。下楼不受是否打开过手册限制。

## 4 T00完整核心体验

### 4.1 一次核档分清两个问题

T00在原大厅核档情境内完成两轮：第一轮核实册子的实际年度，第二轮判断它对应清单的哪一项。它们分别教授单份充分与两份共同证明，使用同一册子和同一内页记录。核心最多出示两份不同身份的材料；一份足够时可直接出示，不能把双槽理解为每次必须放满。

为使两种演出有真实对象，本案增加一条伊万依据封皮作出的初步误判，并把原打钩动作移到第二轮结果收下之后。以下是需同步进最终文案的教程补充，原始script.md保持原件，不把补充伪称为已存在台词。

| 阶段 | 当前问题与依据 | 玩家必须实际经历 |
| --- | --- | --- |
| 首次材料取得 | E01清单按原对白取得 | 看见普通成卡，不点收下 |
| 翻开同一本册子 | 外封皮写1985，首页实际标题为1986年度登记 | 正常点击翻页，取得内页记录并看见普通成卡 |
| 第一轮 | “这本是1985年的登记”与内页标题冲突 | 一张内页卡入槽，第二槽留空，主动出示，矛盾击破 |
| 第二轮 | E01要求1986年度登记，册子实际为1986年度登记 | E01与内页两卡入槽，主动出示，灵感涌现 |
| 结果收下 | 结论为本册对应清单中的1986年度登记项 | 阅读待收卡、主动收下、归位后为该项打钩 |

这一轮只确认年度和清单项目的对应，不证明全年内容齐全、手续全部合规或全站移交完成。教程推论使用独立稳定身份，保留到同一材料集合；第三章P01继续用于原有旧案推论。

### 4.2 单卡充分与矛盾击破

伊万看见旧封皮后新增：“站长拿错了吧。这本是1985年的登记。”艾琳按原核档过程翻开册子，实际看清《1986年度货运收发登记》，取得内页记录。封皮与内页来自同一个柜台物件，不生成两个同义调查点，也不把旧封皮误标为另一本册子。

核对目标明确显示伊万的误判，先高亮这句唯一原话，让玩家点选为当前核对目标，再将箭头转向正确内页卡。选卡时说明：“最多出示两份材料；一份足够时，可以直接出示。”原话显示不等于已经选中，必须完成实际目标选择后才开放选材出示。

玩家选卡后，另一槽保持空白；箭头转向出示按钮。以上都在同一个引导层内随目标变化继续，不另开确认弹窗。第二轮属于已指定问题的自主关联，沿核心规则进入即具有合法问题目标，不重复要求选一句不存在的人物断言。

首次示范期间错误卡暂不可选，正确卡仍须由玩家点击。撤回后回到这张卡的选择，重新放入才开放出示；悬停和入槽都不判定。玩家主动出示后，按单份充分成立，实际来源只记录内页，不自动补入E01凑两张。

判定成功立即撤掉教学遮罩，播放现有5600ms玻璃碎屏版矛盾击破及对应声音，保留裂纹扩展、慢压蓄势、主崩裂、玻璃碎片分层退场及字标。碎裂的是“这本是1985年的登记”这句误判，真实的“封皮印着1985”观察保留。演出回到伊万、艾琳的完整回应，解释旧封皮夹着1986内页；此时只确认实际年度，清单尚未打钩。

### 4.3 两张共同证明与灵感涌现

回应结束后转向第二个问题：“这本册子对应清单中的哪一项？”屏幕保留“要求”与“实际”两个清晰信息区：E01提供待核1986年度登记的要求，内页记录提供本册实际年度。只有一侧材料时，尚未证明两者的对应；不能用同一张卡的两个版本代替两份依据。

教程文字：“把说明要求与实际情况的两份材料放入两槽，再出示。”先高亮E01，真实落入第一空槽后再高亮同一内页记录；两卡落位后转向出示按钮。沿原槽位自动寻找空槽规则，不额外要求玩家先点每个空槽。允许必要撤回，撤回后恢复对应正确材料的指引。

两份材料提交后，分别确认要求与实际相符，播放现有6800ms灵感涌现及声音：来源收拢、五张飞页、字标、末页接触与滑动落定、完整结论显露。此时教学层退出，演出不被下一句说明或菜单盖住，也不在同一次结果上叠放另一段矛盾击破。

两轮使用独立问题、结果及高潮标识。T00的第一次年度误判排除和核档关系闭合作为本次新增教程设计，明确采用完整演出；同一成果重读不重播，不放宽正式主线关卡的演出资格。沿现有effect_kind、effect_level、climax_key及结果时点接入，不新增全局“教程判定模式”。

### 4.4 结论卡与主动收下
