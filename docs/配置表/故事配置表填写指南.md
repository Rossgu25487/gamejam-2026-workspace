# 故事配置表填写指南

游戏直接读取 `game/data/story/outputs/story-images-20261011/故事配置表.xlsx`。使用 Excel 或 WPS 编辑并保存，然后停止当前游戏、重新按 F5 运行。无需生成 JSON、安装 Office 插件或改写 Main。

表内已有可玩的占位案件。可以先只修改名称和正文验证，再逐步替换 ID、材料、说法、问题及证明关系。原系统策划表保持原样。

另有完整虚构短篇[雨夜借阅单示例](雨夜借阅单试玩说明.md)，配置独立保存在`game/data/story/outputs/rainy-images-20261011/雨夜借阅单.xlsx`，打开对应示例场景按F6试玩。原模板仍是F5的默认内容。

## 填写规则

- 保留每张数据表前四行：中文说明、程序字段、类型、分组。第 5 行开始写实际记录。
- `enabled=true` 启用，`false` 暂不使用，引用记录也必须启用。A 列填 `#` 开头的文字可将整行作为备注。完全空白行忽略。
- ID 用英文字母、数字、下划线、短横线和点，区分大小写。ID 与中文名称分开。
- 标题、摘要、原话、正文直接填中文，Alt+Enter 可以换行。不在配置数据中使用 Excel 公式。
- 多个引用使用英文分号 `;` 分隔，如 `A1;B1`。不要使用逗号或中文分号。
- 前 200 个数据行预设格式和枚举下拉，更多行可以复制格式。读取没有 200 行限制。
- 只启用一个案件。改换案件或作不兼容修改时更新 `content_revision`；存读档拒绝其他内容版本的旧档，保留原文件。

本次从 JSON 切换到 Excel 自动文本引用，示例内容版本为 `placeholder-xlsx-1`。此前 JSON 版旧档不与新版混读，文件保留；首次运行选择新游戏建立新自动档，手动旧档保持原位。

## 各表用途

| 工作表 | 填写内容 | 运行用途 |
| --- | --- | --- |
| 案件 | 案件ID、内容版本、初始地点、标题、说明、完成条件/提示 | 初始化、旧档兼容、完成提示 |
| 地点 | 地点ID、名称 | 当前地点与切换 |
| 人物 | 人物ID、姓名 | 说法归属和署名 |
| 材料 | 材料ID、证据/记录/推论类型 | 唯一材料集合 |
| 材料版本 | 内容ID、材料、版序、上一版、标题、摘要、正文 | 精确版本出示与阅读 |
| 人物说法 | 原话版本ID、说法身份、人物、原话材料、原话 | 核对、更正和回查 |
| 问题 | 地点、目标类型、引用、条件、不足节点 | 人物说法或自主推理 |
| 调查入口 | 地点、按钮、正文、材料/说法/事实、来源 | 调查、普通会话和真实取得 |
| 条件 | 条件组、或分支、顺序、类型、引用 | 内容与地点解锁 |
| 出示关系 | 精确目标、1–2份材料、匹配、判定、回应 | 核对、容错、推论、成果 |
| 结果节点 | 回应正文、时点、动作组、下一问 | 回应、待收、继续 |
| 结果动作 | 动作组、顺序、确认/事实/更正 | 业务事务提交 |
| 前次依据 | 当前关系、顺序、前次充分关系 | 前次确认的冻结证明 |
| 地点连接 | 出发/到达地点、按钮、条件 | 普通地点移动，不产生自动存档 |
| 图片布局 | 页面、地点、用途、关联ID、PNG路径、坐标、尺寸、图层、适配方式、条件 | 背景、调查入口、人物图和材料卡面的显示与点击区域 |

建议先填案件、地点、人物、材料和正文，再填问题、条件、入口、结果节点、动作和出示关系。前次依据与地点连接最后补齐。引用在启动时统一检查。

## 核对与证明

`statement` 核对人物说法，填写 `parent` 和 `statement_id`，推理正文留空；`reasoning` 为自主推理，填 `question_text`，人物和说法留空。前者首次需点击原话选定目标，后者自动选定问题。

`contains` 表示包含指定材料即可，`exact_set` 表示集合必须恰好等于所填一份或两份。同一材料的两版不能同时放入两槽。

| feedback | 含义 | 容错 |
| --- | --- | --- |
| full | 充分成立 | 不扣 |
| partial | 局部成立，可补充 | 不扣 |
| counter | 有效反证，但本问题未完成 | 不扣 |
| incorrect | 作者配置的明确错误，需写原因 | 合法提交扣1 |
| 未匹配 | 问题指定的不足回应 | 不扣 |

每题初始3次容错，归零后失败，可主动重试。程序不把所有不匹配材料都视为错误。

充分关系必须有稳定 `result_key`、对应结果节点和包含一次 `confirm` 的动作组。等价解法共享成果ID、动作组、时点、确认范围、表现和推论。例如甲新版单份充分与甲旧版加乙共同充分可共享一个成果。

## 提交与解锁

| timing | 时点 | 用途 |
| --- | --- | --- |
| none | 不提交结果组 | 不足、局部、反证、错误 |
| enter | 进入结果节点时 | 不生成推论的人物更正 |
| continue | 点击继续时 | 不生成推论的事实确认 |
| collect | 主动收下推论时 | 推论及确认、更正、解锁 |

动画完成和跳过都不代替收下或确认。动作支持 `confirm`（确认当前问题，每组一次）、`fact`（增加事实）、`correct`（更正问题合法目标），按 `order` 执行。

不同 `branch` 为“或”，同分支多行为“与”。`always` 独占一个分支且引用留空。`heard` 引用准确说法、`owned` 引用内容版本、`completed` 引用问题、`fact` 引用已知事实。

前次依据每行都要求成立，多行表示共同依据。不同前次解法需要分别填写等价的当前关系。程序从前次关系生成准确目标与快照，不需要手写引用对象。证明引用不得循环。

## 来源、地点与保存

材料来源由实际触发的入口、来源ID、对象ID和入口正文自动生成。推论和确认成果逐层冻结当时的材料版本、路径和前次确认。后来取得新路径不会补入旧证明。

地点连接是单向的，返程需另填一行。调查入口和问题的地点留空表示全局，指定地点则只在该处显示和接受调用。普通地图前往只改变地点，不发放材料、不推进阶段、不触发自动存档；普通自动档沿内容流程正常返回允许调查的节点写入。

## 错误与运行范围

启动校验必填、类型、枚举、重复ID、精确引用、原话正文、材料版本、提交时点和证明循环。标题页显示工作表、行号和原因，禁用开始/继续并保留退出。修正保存后重新运行。

同优先级关系需要避免冲突；实际出示若遇到同优先级的不同成果，程序拒绝判定并提示配置冲突。

新增可选列可加在原表末尾，仍保留四行表头；原工作簿没有这些列也可继续运行：

| 工作表／程序字段 | 类型 | 填写与消费 |
| --- | --- | --- |
| 材料版本／`observations` | `list` | 本精确内容版具备的观察 ID，英文分号分隔。不会从最高版本补入旧版。 |
| 条件／`kind=observation` | `string` | `ref` 填观察 ID；出示时只检查本次所选精确版本。此条件用于关系命中，不能用作调查入口的世界解锁条件。 |
| 出示关系／`a_quote`、`b_quote` | `string` | 材料一／二的准确原句；必须在各自精确内容版正文中只出现一次。结果冻结后用于目标、依据和成立范围对照。 |

接入预检会检查可同时成立、可同选的同优先级关系是否具有冲突成果。复杂的前次证明可达性仍保留运行时复核。

当前可配置：单段调查/会话、材料版本、说法核对、自主推理、两槽出示、容错、收推论、确认、更正、条件解锁、下一问、完成提示、地点切换和现有存读档。

## 图片布局

“图片布局”是可选工作表。旧工作簿没有这张表时，文字界面仍可运行。新增图片时从第 5 行开始填写一条记录：

| 字段 | 填写方式 |
| --- | --- |
| `layout_id` | 唯一 ID，例如 `desk_bg` |
| `page` | `title`、`pause`、`save`、`load`、`settings`、`confirm`、`investigation`、`dialogue`、`selection`、`result`、`material` |
| `scene_id` | 地点 ID；留空表示所有地点 |
| `kind` | `decoration` 背景/装饰，`entry` 调查入口，`portrait` 人物图，`material` 材料卡面 |
| `ref` | `entry` 填调查入口 ID，`portrait` 填人物 ID，`material` 填材料版本 `content_id`；装饰可留空 |
| `image` | 工程内 PNG 路径，例如 `res://art/visual/story_samples/desk_bg.png`；不要填本机绝对路径 |
| `x`、`y` | 左上角坐标，基准画布为 1280×800 |
| `width`、`height` | 显示框尺寸；材料卡面留空，由牌库和阅读器统一排版 |
| `layer` | 图片之间的层级，0–99；页面文字、按钮和弹窗始终显示在图片上方 |
| `fit` | `contain` 保持比例完整显示，`cover` 铺满并裁剪，`stretch` 拉伸填满 |
| `condition` | 可选条件 ID；条件不满足时不显示 |

窗口缩放时，图片位置和入口点击区域按同一比例从 1280×800 映射到当前窗口。`entry` 图片会复用原有调查入口动作和条件校验；图片只改变显示，不改变材料身份、证明关系、地点逻辑或存档字段。正式资源替换时只需把 PNG 放入 `game/art/visual/` 下并修改 `image` 路径，保持 `.png` 扩展名即可。材料卡面不需要填写坐标和尺寸，牌库、出示槽和材料详情页会自动布局。

文案、地图、声音、猫使用各自独立配置，不在本故事表重复维护。文案已有基本阅读与三位置舞台；复杂条件／并列接续、事件步骤、完整会面和结局播放器仍有程序缺口，见[全系统核对](../全系统策划核对与补缺.md)。自动对白播放不在当前策划范围。

导出包包含同一配置表、字段定义及现有规则。运行不依赖 Excel、Python或本机绝对路径。发布包更换内容须重新导出，无运行时热更新。
