## 剩余工作与接入顺序

以下是程序缺口，不能全部归入等待策划或美术：

1. 文案状态桥、复杂接续与完整会面身份；统一手册当前会话。验收多会面、未看分支、旧话更正、核对取消准确返回。
2. 可执行事件调度器与原子结果组、重要镜头恢复。未配步骤不能运行；失败无半批结果；重访、暂停、跳过不重复发卡／执行。
3. 地图、回顾、内容转场统一场景准备／提交及配置强校验。验证取消迟到、越界重叠、坏资源、回焦、读档独立资格。
4. 阶段前后保存、正式指认保护、分支判定、结局播放器及独立续播记录。验证前存至后存各失败点、保护冻结、调查与结局共同继续候选。
5. 手册抽屉与各类型锚点、正式目标生产、对象图片消费者、完整结果分镜。验证容量、返回、图与热点同隐同显、静音／减弱动态结果一致。
6. 全部正文、确认与存档容量／开合时序，完整音频生产；正式包、人工听觉与另一机器验收。

待配：正式地点／人物、材料正文与版本／来源、准确原话／证明关系、目标、阶段／指认／结局条件、合法视图／对象绑定、图片／头像／立绘／猫动作／正式音频。事件步骤需明确动作、目标、资源、时长、等待方式、提交时点与返回入口。继续使用标注占位故事，不从TEST说明推断正式剧情。
