# 调试控制台使用指南

给测试和策划用的图形化控制台：跳章、跳关、给物品、改机会、一键自动通关，全部点按钮完成，不用记命令。

## 1. 呼出

1. 在**任意界面**按键盘左上角的 **`~`**（反引号 / 波浪号键，中文输入法下也行）。
2. 第一次会弹出口令框，输入 `super` 回车。
3. 弹出控制面板。**本次运行之内**再按 `~` 直接开关面板，不再要口令。
4. 关闭游戏后失效，下次启动要重新输入 `super`。

面板打开时游戏是冻结的。`Esc` 或 `~` 关闭面板。

## 2. 七个页签

| 页签 | 用来做什么 |
| --- | --- |
| 概览 | 当前章节 / 场景 / 关卡进度；读完对白、撤回上次跳转 |
| 跳转 | 一键快进到某章、某关、片尾；无条件去某个场景；移动人物 |
| 物品 | 搜索并勾选材料，获得 / 移除；一键拿全部证物、证言、推论 |
| 剧情 | 查入口、事件、条件为什么不成立；手动触发入口或事件 |
| 自动推进 | 让游戏自己玩，出测试报告（见第 3 节） |
| 调试 | 关卡机会、游戏速度（0.5x - 8x）、屏幕状态信息、锁定 |
| 命令行 | 高级用法，输入 `help` 看全部命令，`Tab` 补全 |

页面下方是共用的输出日志，所有按钮的结果都显示在这里。

## 3. 自动推进：测试全流程能不能玩通

最常用的入口是「自动推进」页最上面的**一键预设**：

| 预设 | 含义 |
| --- | --- |
| 通关全流程 | 按通关打法从头玩到片尾，检查每关都能过 |
| 总选第一项 / 总选最后一项 | 对白选项一律取第一个 / 最后一个，测分支 |
| 随机抽测 | 随机打法，种子写进报告，可复现 |
| 错误尝试 | 故意出错，走失败界面和重试 |

点预设后按底部的「开始自动推进」即可。

- **隔离快速**（默认）：在后台临时存档里几秒跑完，**不影响你当前的游戏**。
- **实机演示**：在真实游戏画面里自己玩，能亲眼看，屏幕上方有横幅，点横幅或按 `Esc` 停止。默认不写自动存档，结束后可用「撤回」回到演示前。
- 目标可以是片尾、某一章或某一关；起点可选新开一局或从当前进度继续。

**看报告**：顶部一行是通过 / 未通过；下面是覆盖率（章节、关卡、材料等）和异常列表。「在日志里展开详细报告」可看逐关明细和最近动作，「复制报告文字」可直接贴给开发。完整 JSON 在 `autoplay_last.json`（点「打开报告文件夹」）。

异常分两级：**错误**（走不下去、存档损坏、界面与状态不一致等，会判未通过）和**提示**（选项被游戏拒绝等）。

## 4. 常见用法

- **直接测第六章**：跳转页点 `CH06`。点错了点「撤回上一次跳转」。
- **测某一关的失败界面**：跳转页选关卡 → 「跳到所选关卡」；调试页 → 「全部关卡清零」后出示错误材料。
- **缺材料**：物品页搜索 → 勾选 → 「获得所选」，或直接点「获得全部材料」。
- **想知道某个入口为什么点不开**：剧情页选中它 → 「解释入口条件」，会逐项显示卡在哪个条件。
- **嫌慢**：调试页把速度调到 4 倍或 8 倍。

## 5. 注意

- 跳转会**替换当前进度**（后台沿真实流程推进，不是直接改存档）；跳转前的进度会留一份，点「撤回上一次跳转」找回。
- 跳转和自动推进进行中，面板会盖一层遮罩，点「取消」或按 `Esc` 终止，不会改动当前进度。
- 控制台只在内存中解锁，不写入存档。
- 反馈问题时请附上：自动推进报告文字（或 `autoplay_last.json`）和随机种子。
