# 团队工作台怎么用

**入口：[打开团队工作台](https://rossgu25487.github.io/gamejam-2026-workspace/)**。队员直接用浏览器访问即可，查任务和排期无需先启动 Godot。岗位 MD 已单独分发，作为本人 Codex 的工作参考。

## 看工程版本

“当前工程”显示共同 `main` 的短提交号、更新时间和改动说明。打开提交可以查看具体变化，“下载源码”取得对应提交的完整工程。

可试玩版本另行显示：主程序实际发布后才有运行包；源码 ZIP 需要用引擎打开。网页不会把源码下载当作可试玩包，也不因 main 更新就宣称运行测试通过。

开始工作时，让 Codex 核对本人分支和共同版本；有未提交工作先保留。Godot“协作空间”里的本机提交可以辅助比对，重新进入该页会读取当前副本。

## 看与更新任务

1. 按岗位和阶段筛选，找到本人的准备或制作任务；搜索可按标题查找。
2. 点开任务，阅读完成条件和接收者。在 GitHub 任务记录中补充成果位置、提交或运行包版本、实测结果、未测项及下一步。
3. 任务验收完成后选择 **Close issue**；网页显示为“已完成”。取消的事项用关闭菜单中的 **Not planned**，不会混入完成数量。
4. 需要细分状态时，添加 `status:doing` 表示进行中，`status:review` 表示待验收；切换时移除旧状态标签。普通未关闭任务默认为待完成。

“新建任务”打开简短任务表，只写目标、完成条件、交付位置及时间依赖。用 `role:<岗位ID>` 标记负责岗位；本人加入后，可将 Assignees 指派到具体账号。岗位分工和 GitHub 权限分开管理。

岗位筛选中会列出已确认成员；任务卡优先显示 GitHub 显式指派，原生指派为空时显示已确定的“岗位负责人”。页面顶部“成员管理”供队长查看实际协作者和待接受邀请。当前仓库属于 Rossgu25487 的个人账号，尚未建立 Organization。

赛前任务使用 `phase:preparation`，正式开题后确定的制作任务改用 `phase:production`。所有人完成准备需要本人实际确认，搭建者的历史检查不能代替成员验证。

可以交给本人的 Codex：

> 请查看我负责的 GitHub 任务及当前工程版本，保留已有修改，按本轮明确范围执行。完成后整理交付位置、版本、实际验证和剩余问题，更新对应任务；验收已获明确授权且条件满足时再关闭。本人交接文件只留下下一次恢复需要的信息。

## 看排期

所有时间按北京时间显示。排期分为已确认节点与建议节点，内部截止仍是 **2026 年 10 月 19 日 00:00**。10 月 17 日首提属于建议。

日期到达只表示时间已到，节点是否完成仍以相关任务与提交证据为准。题目公布后再补具体制作排期，正式制作每人累计最多 12 小时。

排期由队长维护 `workspace/roadmap.json` 并同步到 main；具体任务记录负责人、依赖与预计投入，个人实际工时由本人确认。

## 策划案与成果放哪里

策划原件由队长或其 Codex 放到 `planning/inbox/`，保留原件；明确采用后更新 `planning/current.json` 的文件路径与内容哈希，并与有关需求一起提交。也可以从 GitHub 的 planning/inbox 目录上传文件，再让 Codex 核对当前依据。

一个任务引用对应的策划文件或需求 ID。成果优先附 PR、仓库文件或实际运行包链接，接收者可以直接打开；只写本人电脑路径无法完成跨机器交接。

仓库与网页公开，只提交适合公开的资料；账号凭据和不宜公开的原件留在仓库外。

## 刷新与异常

网页显示最近获取数据的时间。发布快照来自 GitHub，成员刷新时可再次获取；网络请求失败会保留已有内容并提示失败，不能把旧数据当作刚刚更新。

打开网页时会自动获取 GitHub 当前数据；队友更新任务或 main 后，再点击刷新即可读取。网络受限时可打开具体 GitHub 任务核对源记录。网页不把浏览器里的临时勾选当作全队完成状态。

找不到任务时先取消筛选；尚未发布试玩版时联系主程序确认交包安排。需要账号登录、接受邀请时由本人完成。

## Godot 入口与换岗

Godot 用来制作、运行和检查游戏；顶部“协作空间”提供网页、仓库和任务快捷入口，并显示本机版本。旧版岗位长文、交接编辑和策划导入页面已退出日常入口。

换岗时先交接原任务与未完成成果，再按新分工使用对应工作流和独立分支。成员通常无需重新邀请；同一目录同一时间由一个明确负责人写入。

更多 Git 步骤见[加入与同步](加入与同步.md)，负责目录见[协作协议](协作协议.md)。
